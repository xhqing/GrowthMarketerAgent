## 〇、档位总则（2026-10-02 定案，先看这一节）

| 场景 | 用哪个档 | 说明 |
|---|---|---|
| **默认（480p / 720p 交付）** | **mini** | 一遍出片；最便宜、最快、同分辨率画质不输 2.0；**不要"低清打样 → 高清定稿"两遍生成** |
| **1080p 交付 · 预计抽 ≥3 次** | **2.5 样片模式** | 480p 样片（¥3.35/5s）→ 成片只能 1080p（¥18.7/5s）；断点 N≈2.07 |
| **1080p 交付 · 一次成** | **2.0 直接出** | ¥12.40/5s，比"样片+成片"（¥22.05）便宜 |
| **需要 2.5 的独占能力**（30 秒一镜到底 / 强指令控制 / 多镜头一次生成 / 视频编辑 / 长度延长 / 口型与多语言对白 / 50 个参考素材） | **2.5**（480p 或 720p 均可） | **这一条与分辨率无关**——即使交付 480p，只要需要这些能力就用 2.5 |
| **fast / 2K / 4K** | **不用 / 不考虑** | fast 是旧档且贵 60%；2K/4K 超出当前交付需求 |

**判定顺序**：① 有没有"2.5 独占能力"需求？有 → 2.5；② 没有 → 看在哪个分辨率交付：≤720p → mini；1080p → 按预计抽卡次数在 2.5 样片模式与 2.0 直接出之间选。

**「一镜到底」怎么选（2026-10-02 查证）**：单段时长上限——**2.0 全系（含 mini / fast）= 4–15 秒**，
**2.5 = 4–30 秒**。所以：
- **≤15 秒的一镜到底 → mini 完全够**（独立实测：15 秒四节拍镜头「进门→穿过→坐下→开笔电→台词」**三档都走完并全程保住角色**，
  mini "$1.14 那次和旗舰 $2.27 那次一样"；字节自家页面也称 mini 在 8–10 秒后的时间性瑕疵更少）；
- **16–30 秒 → 只能 2.5**（唯一支持 30 秒直出）；
- **提升长镜头成功率的写法**：把提示词写成**时间轴 / 分镜表**（按时间顺序写清每段动作与景别变化），
  长镜头里"细节约束"（如"必须坐在靠窗那张桌"）容易被丢——**三档都一样丢**，写完要逐帧核对。

## 一·五、抽卡次数参考（成本公式的第二半，2026-10-02 查证）

**总成本 = 关键帧 +（每镜抽卡次数 × 镜数 × 5 秒 × 单价）**。单次单价压到最低（见决策规则），
**抽卡次数才是另一半**——以下为可参考的口径（公开数据多为经验值/发布期口径，无按档位横评的实测）：

| 口径 | 数值 | 来源性质 |
|---|---|---|
| 行业平均可用率 | **< 20%**（"至少生成五次以上才可能出一条过关的"） | 行业共识，多家媒体 2026-02 转述 |
| Seedance 2.0 可用率 | **> 90%**（发布期内测口径；有评测者连出十几段无废片） | ⚠️ 发布期宣传/体验口径，非长期统计 |

| 复杂镜头（先预演再生成） | **2–3 次**（"砍掉七成"） | 同上（预演成本另计） |
| 简单镜头 / 短镜头（3–5 秒） | 一次出 3–4 条批量筛，命中率高 | 经验做法 |

没有证据说明贵档更省抽卡**。

### ⚠️ 默认抽卡策略：**先抽 1 张，通过即用**（2026-10-04 用户定，推翻"每镜默认 3 抽"）

**默认流程**：每镜**只先提交 1 条**（首帧模式、5 秒）→ 立刻按质检清单验收 → **通过就定稿，不再抽**；
**不通过**才抽第 2 条，仍不通过才第 3 条。**禁止一次性批量抽 3 条"备选"**。

**为什么**：本项目实证——CRUNCH 8 个镜头里 **6 个第一张就通过**（③④hero 新碗镜 ① 修复都用 take1）。
默认抽 3 条时，这 6 镜白花 ≈ **¥14/片**；加上"重出尝试每轮也抽 3 条"的浪费，本片本可少花 **≈¥18–19**
（实际 ¥45.4 → 约 ¥27）。**视频生成这一项的开销预期降 55–65%**（从 3 抽/镜 → 约 1.2–1.4 抽/镜）。

**例外（要一次抽 2–3 条的场合，需在 brief 写明理由）**：
① 动作方向 / 印字可读性天然随机性大、**"选条"比"过没过"更重要**的镜头；
② 交付时间紧、并行生成明显省时（3 条并行 ≈2 分钟 vs 串行 3 轮 ≈6 分钟）；
③ 客户明确要求"多给几条挑"。

**同一条原则也适用于关键帧**：关键帧默认**只出 1 张**，不通过再重出（不要连出 3 张挑）。

**降低抽卡次数的免费手段**（按优先级）：① **首帧模式**（锁构图，已在用）；② 提示词写具体
（物理 / 方向 / 印字 / 不静止，少让模型猜）；③ **先用 3–5 秒短镜头**（成功率远高于长镜头）；
④ **固定 seed**（API 顶层字段 `seed`，默认 -1=随机，**范围 [-1, 4294967296]**；**mini 实测可传**（越界会报 "for model doubao-seedance-2-0-mini"）；同 seed「生成相似结果，**不保证完全一致**」——用于微调局部时减少漂移。本 skill 的 `scripts/ark_seedance.py` 已支持 `--seed`）；
⑤ 简单镜头一次出 3–4 条批量筛；⑥ 复杂镜头才考虑预演（3D 白模 / 分镜，成本另计）。
**记录习惯**：每条片子把「每镜抽卡数 + 任务 ID」记进 brief，攒几条后就有自有基线（比引用宣传口径可靠）。

## 二、决策规则（每次开工照此给方案）

0. **性价比结论：mini 是综合最优档（2026-10-02 定）**——单价最低（480p ¥0.23 / 720p ¥0.50 元/秒）、
   权重最新（快照 260615，仅晚于 2.5）、同分辨率画质与 2.0 无稳定差（甚至因代际更新在运动连贯 / 提示词遵循上更好），
   且最快。**省下的钱买「更多次尝试」才是真正省钱**：生成不可复现，最大成本项是重抽，
   「Mini 六次的价钱 = 旗舰三次」。**mini 只在三种情况下不是最优**：要 1080p / 4K（用 2.0）、
   要「高清且与低清样片内容一致」（用 2.5 样片模式）、要电影感取向 / 复杂镜头语言（2.0 有余量，看片子值不值）。
1. **交付多少分辨率，就选那条最省的路径（2026-10-02 算账定）**：
   | 交付分辨率 | 最划算路径 | 单价 | 5 秒一条 | 关键理由 |
   |---|---|---|---|---|
   | **480p** | **mini 一遍出片** | ¥0.23/秒 | ¥1.15 | 最便宜档就是它；同分辨率画质不输 2.0；**样片模式用不上**（它只通向 1080p） |
   | **720p** | **mini（不是 2.5）** | ¥0.50/秒 | ¥2.50 | 2.5@720p 要 ¥1.51/秒（**3 倍价**），且样片模式终版口径是 1080p，720p 用不上——2.5 的价值在 30s / 指令控制 / 编辑延长，不在 720p 性价比 |
   | **1080p（只出 1 条）** | **2.0 直接出** | ¥2.48/秒 | ¥12.40 | 只有 2.0 / 2.5 能做 1080p；此时 2.5 样片模式（¥3.35×1+¥18.7=¥22.05）**比 2.0 直接出更贵** |
   | **1080p（预计抽 ≥3 次）** | **2.5 样片模式** | — | N=4：¥32.1 vs 2.0 的 ¥49.6 | 断点：3.35N+18.70 = 12.40N → **N≈2.07**；N=3 起样片模式更便宜（N=4 省 35%、N=20 省 65–77%），且**保结构 / 保动作 / 保节奏** |
   | **4K** | 2.0 | ¥5.05/秒 | ¥25.25 | 唯一支持 4K 的档 |
   口径说明：样片模式 = N×5×¥0.67（480p 样片）+ 5×¥3.74（1080p 成片）；2.0 直接出 = N×5×¥2.48。
1. **默认一遍 480p 出片（2026-10-02 用户定）**：**用 mini 480p 生成一次即可交付**——手机端（视频号等）
   全屏观看时，480p 放大到 720×1280 与原生 720p **肉眼几乎无差别**（实测清晰度差 5–6 倍，但全屏观看感知不到）。
   **默认口径下一条片的成本 ≈ 关键帧 ¥1 + 480p 生成 ¥4.6（4 镜×5 秒）≈ ¥6**。
1a0. **要「高分辨率 + 与低清样片内容一致」时 → 用 2.5 的官方样片模式（Draft mode）**：第 1 步 480p 生成样片（便宜、随便抽），选定后第 2 步基于样片出 1080p 成片、**内容高度一致**——这是产品化的「打样 → 定稿」，比「低清档位打样 + 高清档位重跑（重新抽卡、内容会变）」正确得多。代价：2.5 1080p ¥3.74/秒（5 秒 ≈ ¥18.7），只在高价值镜头用。
1a. **要更多「像素」时先升分辨率、别升档位（2026-10-02 查证）**：mini@720p（¥0.50/秒 ≈ ¥2.5/条·5 秒）比 2.0@720p（¥0.99/秒 ≈ ¥4.95/条）**便宜一半且同画质**——分辨率是能力、档位是费率；旗舰 2.0 只为 1080p / 4K 付费。
1b. **「打样 → 定稿」两遍生成是错的（2026-10-02 修正，本项目实战教训）**：**重新生成 = 重新抽卡**，
   内容会变（道具数量 / 动作 / 印字 / 音轨都可能不同）——**打样确认过的结果在定稿里保不住，打样就失去意义**。
   需要「只提分辨率、内容不变」时只有两条路：① **超分**（内容不变；火山侧在「AI 数据湖服务 → 视频超分 /
   视频分辨率调整」与「视频点播 → 画质增强」等**独立产品**里，不在 Ark 模型列表内，需单独开通与计费）；
   ② **接受重抽**：把它当**新一次抽卡**处理——预留重抽预算、结果**重新验收**，并事先向客户说明「内容会变」。
   推论：**生成时就按目标交付分辨率出**（默认 480p），一次成型；不要指望"先低清打样、后高清定稿"。
2. **分辨率阶梯**：**480p = 默认交付**（生成用 mini，输出仍按 9:16 标准 720×1280 放大）→
   720p 仅在明确需要时（展示 / 大屏 / 客户要求）→ 1080p 只在客户明确要求时。
   为什么可以这么省：主流平台都会二次压缩，手机端全屏观看分辨不出；480p 的生成成本只有 720p 的约 23%
   （mini 0.23 vs 2.0 0.99 元/秒）。若客户对清晰度敏感，再补 720p 定稿即可（重新生成 4 镜 ≈ ¥19.8）。
3. **模型分级**：多镜头剪辑 → **2.0**（静态画质好又便宜）；一镜到底 / 强表演 / 口型 / 编辑 /
   延长 → **2.5**；极致省钱 → fast / mini。
   **关于「指令控制」**：2.5 官方宣称「更强的指令控制」（且支持 30s 直出、最多 50 个参考素材、
   专业级编辑 / 延长）——**但文本提示始终是软条件**：动作方向、否定句（「不要向上」）这类约束，
   2.0 实测控制不住（冰块仍先上后下），2.5 也不保证；**硬控制靠三件事：首帧设计、构图规避、
   剪辑取段**（见 `SKILL.md` 流程第 4/5 步）。需要更强指令控制时，2.5 值那 50% 溢价（720p：
   1.51 vs 0.99 元/秒）再试，但别把它当物理引擎。
4. **首帧模式优先**：先用 Seedream 出关键帧，再用 Seedance 以关键帧为首帧生成（`--image`）：
   构图锁定、明显减少抽卡次数——**控制成本的第一杠杆**。
5. **镜头长度**：每镜生成 5 秒、剪辑取 2–3 秒；按需求控制总片长，不拍多余素材。
6. **素材复用**：一条素材多次剪（换钩子 / 换片尾 / 拆条）；品牌资产（产品图、关键帧、品牌卡）复用。
7. **图片侧**：默认 **lite**；只有精细文字 / 高精度编辑才用 pro；分辨率 2K 封顶（4K 仅在确有
   需要时）；参考图数量控制（首张免费、其后 0.02/张）。
8. **先用免费额度**：优先用掉官方免费额度与活动资源包。
9. **按原始生成秒数估算**：成本 ≠ 成片时长——每镜生成 5 秒、剪辑只取 2–3 秒，
   估算公式 = 镜数 × 5 秒 ×（打样单价 + 定稿单价）；用成片时长估会少算近一半。

## 四、把成本压到最低但结果可控

- **关键帧先行**：先构图后生成，抽卡次数从「按条抽」变「按镜挑」；
- **一镜一挑**：同一镜跑 1–2 条就定，不满意的先改提示词再跑（不要一次性抽一堆）；
- **短片优先**：4 秒钩子 + 4 秒演示 + 3 秒产品 + 3 秒 CTA 的 15 秒结构，素材利用率最高；
- **复用与拆条**：一条 15 秒素材可拆两条钩子变体（换前 3 秒），边际成本接近 0；
- **零成本层**：音效 / 音乐用免费商用库；品牌卡 SVG 渲染；剪辑与字幕都是本地算力。

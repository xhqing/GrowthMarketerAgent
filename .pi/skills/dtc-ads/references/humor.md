# 幽默广告工艺（泰式幽默的可复用做法）

> 来源：Creative Review《Why humour is a serious business in Thai advertising》（Leo Burnett Thailand 创意人 Thiti Boonkerd 访谈）、
> Sinema《Analysis: What Makes Thai TV Commercials Work?》、人人都是产品经理《有"毒"的泰国广告，怎么学？》、
> 界面《泰国广告的脑洞流水线》。整理日期：2026-10-02。

## 一、为什么泰国广告好笑（成因，不是"天赋"）

1. **文化成因——自嘲式幽默**：泰国人的幽默来自"现实生活不好笑"：
   博恩克德原话「泰国人好笑，是因为我们的现实生活一点都不好笑……泰国人在艰难处境里找办法'一笑而过'，这是释放压力的方式」；
   → 幽默的**内核是"共情 + 自嘲"**（讲的是多数人的困境），不是嘲笑别人。
2. **行业成因——"喜剧是严肃生意"**：1970 年代跨国广告公司进入、长期媒体管控反而抬高创意的价值、
   广告业是顶尖创意人的首选去处 → 高手密度高、制作水准高（笑点背后是**大量工艺**）。
3. **审美成因——重情感、轻说理**：Thai 广告几乎不放数据、不靠明星光环，靠 **pathos（情感）**——
   这正是它**跨文化传播**的原因（看不懂语言也能笑/哭）。

## 二、可复用的叙事机制（工艺层）

| 机制 | 说明 |
|---|---|
| **铺垫 → 抽地毯** | 博恩克德：「美主要在**你怎么讲**：铺垫、累积、**什么时候抽地毯**、**怎么把它绕回产品**，全都连着」——笑点只是起点，节奏才是本体 |
| **类型错位（genre misdirection）** | 开场用**别的类型的视听语气**（灾难片/恐怖片/西部片/纪录片），让观众预设错类型 → 反转时落差最大 |
| **产品即笑点** | 产品不是贴片，而是**最后一个 punchline 的组成部分**（"allows the product to be part of the punchlines"） |
| **一本正经演荒诞（deadpan）** | 越荒诞的事，越要用**电影级正经**的表演、运镜、音效去拍——反差才成立 |
| **强烈反差** | 行业调查：泰国广告特质里"煽情走心"81%、"搞笑幽默"60%、"强烈反差"57%（同一支片子常常先笑后泪） |

## 三、压进 15 秒：唯一的改编要点

泰式幽默长片通常 60–180 秒——**铺垫足够长，反转才够响**。15 秒版本不能照搬，只能：

> **用"类型视听信号"代替长铺垫**：开场 2 秒给足类型暗示（恐怖的配乐+低角度、西部的正午沙地、纪录片的旁白），
> 观众自己脑补出整个类型语境 → 你花 2 秒买到了原本要 60 秒建立的预期。

15 秒结构（照此排）：
```
0–2s   类型钩子：用类型片语气开场，让人"以为在看别的"
2–10s  铺垫与升级：一个动作/情境被推向荒谬（重复 → 升级；三次法则）
10–12s 抽地毯：意料之外的反转
12–15s 产品即笑点：产品以荒诞但合理的方式出场，落最后一个笑点
```

**纪律**：① **一支片子只有一个笑点**（两次反转 = 都不响）；② 认真到底（不用"搞怪表情/夸张音效"代替内容荒诞）；
③ **不冒犯**：笑点来自"情境荒谬"，不来自嘲笑任何群体（合规红线）；④ **静音可懂**：TikTok 自动播放无声，靠画面推进。

## 四、AI 生成（Seedance）的能做 / 不能做

**能做（优先用）**
- **不可能的物理**：水往上流、重力失效、物体自己动——模型天生会"搞错物理"，**错误物理就是免费笑点**；
- **拟人化**：动物/物体做出极其认真的专业动作（deadpan 的天然载体）；
- **类型片质感**：灾难/西部/恐怖/纪录片语气，AI 出"电影感"很稳；
- **单主角 + 单动作**的视觉喜剧；静音可懂。

**避坑（不碰）**
- 复杂对白 / 口型（贵且易崩）、多人互动（人数/手指易错）、长镜头人脸特写（崩脸）；
- 依赖"语言梗 / 谐音 / 双关"的笑点——跨文化翻译必丢。

## 五、点子模板（可套用）

| 笑点机制 | 模板 |
|---|---|
| 类型错位 + deadpan | **末日/灾难现场**里，主角面无表情地继续做日常小事（喝饮料） |
| 拟人 + deadpan | **动物**以极其专业的姿态指挥人类（猫当动作指导） |
| 类型错位 + 产品即笑点 | **西部决斗 / 抢劫 / 追逐**，争抢的其实是冰箱里最后一罐 |
| 不可能物理 + deadpan | **重力局部失效**，只有主角的水在往上飘，所有人都无视 |
| 伪纪录片 | 用动物纪录片语气拍"厨房里的野生人类" |
| 恐怖片语气 + 拟人 | **产品自己逃跑**，用恐怖片追逐镜头追它，最后它自己回冰箱 |
| 落差反转 | 极限运动大场面 → 拉远发现是办公室里脑补 |
| 三次法则 | 同一动作前两次笨拙、第三次极其优雅 → 然后翻车 |

## 六、体感时长 = 事件密度（2026-10-03 实战教训）

**同一批观众反馈：14 秒的「感官循环」体感比 15 秒的「Doomsday Sip」长得多，后者"空洞、一下就没了"。**
差别不在物理时长，而在**可感知事件数**：

| 维度 | 感官循环（14s，体感长） | Doomsday Sip（15s，体感空） |
|---|---|---|
| 镜头数 | **4 个不同主体**的镜头 | 1 个镜头（一镜到底） |
| 视觉事件 | 冰落→注水→罐身凝露→最后一口→hero→品牌卡（**6 个**） | 弹碎屑→砸落→喝→举罐（**4 拍且重复**） |
| 可读信息 | **4 句旁白 + 4 行字幕** | **0** |
| 声音变化 | 冰裂 / 注水 / 气泡 / 金属，**层层不同** | 单调低频（薄） |
| 剪辑节奏 | 每 2–3 秒一个切点（**章节感**） | 无切点（**没有时间刻度**） |

**规则**：
1. **一镜到底（one-take）是"信息密度最低"的形式**——它在长片里靠表演撑，短片里必然空；要用就必须**内部塞 3 个以上的升级 beat**，且**必须有旁白/字幕**补信息；
2. **每 2–3 秒必须有一个"新事件"**（新画面 / 新动作 / 新声音 / 新文字），否则观众提前"看完"；
3. **喜剧要 2–3 个升级**（rule of three 的变体），单一梗重复 = 空；
4. **旁白/字幕是信息密度的免费来源**（我们本来就有 TTS 管线）——幽默片尤其适用**伪纪录片旁白**：一本正经地解说荒诞（如"Here we observe the suburban male in its natural habitat."）；
5. 需要"体感扎实"的片子 → **默认多镜头**（4–6 镜），一镜到底只在有明确理由时用。

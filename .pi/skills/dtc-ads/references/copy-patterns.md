# 英文文案库（卖点 / 钩子 / 结构 / 结尾与 CTA）

> 默认全英文产出；以下模式可直接套用后按产品改写。
> 语言纪律：一条片只用一种语言——英文版就从头英文到尾，字幕、品牌卡、旁白同一语言。

## 一、一句话卖点（先定它，再写别的）

格式：**给谁 + 有什么不同 + 凭什么**。先用中文把这句话写清楚，再翻译成片子里的一行英文：

- `Finer fizz. To the last drop.`（气泡更细、持久到最后一口）
- `Ice-cold. All the way home.`（冰感）
- `One wipe. Zero streaks.`（清洁类：结果前置）
- `Stays cold for 24 hours.`（保温类：数字 + 时间）
- 通用句式：`[结果 / 差别]. [时间 / 程度].` 或 `[Benefit] — [原因 / 证据].`

**证明方式**（至少选一种拍出来）：细节微距（细到看得见）、对比（普通 vs 它）、
时间压缩（几小时后依然）、极端条件（冰 / 火 / 摔 / 压）。卖点不落地成镜头，就是空话。

## 二、Hook 公式（0–3 秒，写画面能拍出来的）

> **⚠️ 2026-10-07 用户口径（优先于下面的模板）**：**Hook 一般不出现产品** —— 第一镜用**夸张化的痛点场景**开场（观众先看见自己的麻烦），**产品在中段作为「解法」首次出场**；卖点句随产品出场时说出（不必强塞进前 2 秒），收尾复述一次。
> 参考：CRUNCH 的结构（① 狗嫌弃旧狗粮 = 痛点/历史 → ③ 才出现产品）就是按这个逻辑改的。
> 实操注意：**"金属被掰弯/折断"这类静帧 AI 画不准**（2026-10-07 实测：铲子撬弯 → 画成完好铲勺 ✗）→ 夸张道具选**AI 画得准**的（电钻 / 钢丝刷 / 一堆报废工具 / 工业量级器材 ✓）。

| 类型 | 句式 | 例 |
|---|---|---|
| POV 点名 | `POV: you [pain / identity]` | `POV: you've bought the wrong one three times.` |
| 反常识 | `Stop [common behavior]` | `Stop buying [category] without checking this.` |
| 悬念 / 测试 | `I tested [X] for [time]…` | `I tested 5 [category] in 5 days.` |
| 结果前置 | `[Result] in [time].` | `Silky hair in one wash.` |
| 视觉冲击 | 无文案，画面先炸 | 爆裂 / 融断 / 飞溅 / 慢镜 |
| 质疑回应 | `I thought [X] was a gimmick until…` | `I thought this was a gimmick. Then I tried it.` |
| 身份认同 | `If you're a [identity], this is for you.` | `If you drink three coffees a day, this is for you.` |

写钩子的三条纪律：短句；静音可读；不解释背景（背景在中段讲）。

## 三、15 秒结构模板

```
0–2s    HOOK     视觉冲击 + 一句话卖点字幕（最迟 2 秒内说出）
2–7s    DESIRE   使用瞬间特写（越 satisfying 越好）
7–11s   PROOF    一个证明卖点的镜头（细节 / 对比 / 时间 / 极端条件）
11–15s  收尾     品牌 + 产品（默认无 CTA；客户要求时加引导语）
```

## 四、30 秒结构模板

```
0–3s    HOOK       视觉冲击 + 一句话卖点字幕
3–10s   PROBLEM    让观众看见自己的麻烦（画面 + 字幕）
10–20s  SOLUTION   产品出场 + 演示 + 卖点展开
20–26s  PROOF      至少一个证明镜头（细节 / 对比 / 时间 / 极端条件）
26–30s  收尾       品牌 + 产品（默认无 CTA；客户要求时加引导语）
```

## 五、结尾与 CTA（默认不做）

**默认**：结尾只呈现品牌与产品，不放 CTA、不在画面里画按钮——`Shop Now` 这类按钮是广告系统自带的（可点击的），视频里画一个点不了的按钮没有意义。

**客户明确要求 CTA 时**，用一句引导语（字幕或口播），例如：

- `Tap the link below to shop.`
- `Link in bio.`
- `Tap below to get yours.`
- 中文渠道：「点击下方链接购买」

**禁用**：`Watch it again` · `Watch till the end` · `Rewatch` · `See you next time` ·
`Stay tuned` · 任何让观众留在视频里的号召；也不要用问句做 CTA。

## 六、品牌卡规格

- 默认：`BRAND` + 产品画面（或一句利益点），两到三行以内；**不画按钮、不放 CTA**；
- 客户要求 CTA 时：加一行**引导语**（不是按钮图形）；
- 停留 ≥ 2 秒；浅底深字或深底浅字，保证小屏清晰；
- 英文排版用无衬线（Inter / Helvetica / Futura 类），大写 + 字距；
- 中文版（若用户明确要求）单独整版渲染，不与英文混排。

## 七、字幕规范

- 无衬线、大写优先、下安全区居中；一行不超过 ~22 字符（竖屏 9:16）；
- 只写必须说的：hook 一句、卖点一句（收尾如需 CTA 再加一句引导语）；不写口语废话；
- 拼写与标点逐条核对——英文错字比中文错字更显廉价；
- 需要中文版时整条统一中文，单独输出一版文件。

# 内容形态模板库

X 引流内容的六种形态模板与操作 SOP。机制依据见项目根 `x-algorithm.md`，
SKILL.md 的六条铁律在此不再重复——所有模板默认已过铁律，用的时候只需关注形态本身。

## 一、单帖三型

### 1. 对话钩主帖（常规主力）

结构：**具体场景钩子 → 展开 2-4 句 → 开放问题收尾**。钩子要具体（有数字、有场景），
不要抽象口号。

对照示例（`x-post-minimal-agent-03` 的骨架）：

> The smallest useful agent I run is 56 lines.        ← 具体钩子（数字）
> One identity file. Five sections: ...               ← 展开（清单式，易读）
> That's it. No framework. No orchestrator.           ← 断言收尾
> You don't start with a swarm. You start with one hire that ships.   ← 可辩论观点
>
> [link in reply]                                     ← 零外链惯例

写完自问：这条帖子有没有一个值得别人回一句「我不同意，因为……」的点？没有就加。

### 2. 观点断言帖（争议换覆盖）

一句话断言 + 2-3 句论证。断言要能站得住又有人不同意（「Org > accumulation」式）。
争议度上限是「建设性对比」——可以点名比较方法，不可以嘲讽人（铁律 5）。

### 3. 算法帖（现成热点，零额外成本）

「我从 X 开源算法里读出的 N 条发帖铁律」——蹭双热点（AI + 平台算法透明化），
内容直接改编自 `x-algorithm.md` 第一、二节。首发模板：

> I read X's open-sourced algorithm so you don't have to.
> 6 rules for posting that the code actually rewards:
> （下方列 6 条机制要点）

这类帖子自带meta吸引力：读算法的帖子本身按算法规则发。隔几个月算法有新 release
（Scout 快照换版）就可以重发一版「what changed」。

## 二、干货 thread 节奏设计

Thread 完成率是排序信号（读者读完本身加分），所以节奏比信息密度重要：

1. **首帖必须是钩子不是目录**——一个反直觉结论、一个数字、一个「我怎么走到这的」，
   让人有点开第 2 节的理由；
2. **每节 3-5 行**，一节只讲一件事，节尾留半句悬念或小钩子（「But that created a new
   problem:」式过桥）；
3. **中段防流失**：把最强的一条干货放在第 5-7 节（中点是流失高发区），在第 3 节末尾预告它；
4. **末节 = CTA + 开放问题**：链接放末节 + 首条回复（部分客户端折叠帖尾链接，双保险），
   然后留一个开放问题引回复——thread 读完 + 有人回复 = 双信号。

结构参照 `artifacts/playbook-launch/x.md` 的 Launch thread（10 节：钩子 → 来历 →
方法 → 团队 → 机制 → 纪律 → 收据 → 边界 → 定价 → CTA）。

## 三、重发钩子操作

同一条干货隔 3-4 天重发是正当操作（6 小时半衰期，重发 = 第二次入池），但**必须换钩子**——
原样重发既浪费（已看过的人再刷到是负反馈候选），也难看。操作：

1. 保留干货内核（同一套机制 / 数字 / 结论），只换**入口钩子**：
   - 数字钩 → 问题钩（「你有没有算过你每月为用不到的 AI 订阅付多少钱」）
   - 故事钩 → 断言钩（「division of labor beats one giant prompt, every time」）
   - 第一人称 → 第二人称（「我踩的坑」→「你可能正在踩的坑」）
2. 换形态：thread → 单帖、清单 → 叙事；
3. `utm_content` 重新分配（`x-post-<主题>-02` 式新序号）并登记 `plan.md`——
   重发是独立内容、独立归因，才知道哪个钩子有效。

## 四、回复区链接 SOP

- **发帖前**就写好首条回复（完整 UTM 链接 + 一句引导语，如「Full breakdown + templates:」），
  发帖后立即跟上——不是等有人问再放；
- 单帖结构：正文以 `[link in reply]` 收尾引导；
- 帖串结构：末节放链接 **并且** 首条回复再放一次（部分客户端折叠帖尾链接）；
- 评论区有人问「链接呢 / 在哪买」：直接回链接（这条回复还会被后来者看到，等于免费广告位）；
- **作者回应他人回复值 +75**（≈150 个赞）——评论区每一条实质回复都值得认真回，
  这是全平台性价比最高的互动动作，优先级高于发新帖。

## 五、bio 与置顶「Start here」帖串（常青层）

- **bio 链接**：落地页 UTM 链接（`utm_content=x-bio`），一句定位语讲清「这个账号给你什么」；
- **置顶帖**：Launch thread 或专门的「Start here」帖串——每个点进 profile 的人先落到它，
  profile 点击 +12 是高价值信号，置顶帖就是这个信号的转化承接；
- 置顶帖按**常青标准**写：不含时效信息（没有「今天」「本周」），数字口径长期有效，
  定价信息与落地页当前一致；
- 站内搜索是长尾通道之一：置顶帖与 bio 里的关键词按「别人会搜什么」埋（agent team、
  multi-agent、Claude Code、agent org……）。

## 六、每日养号动作（TweepCred 纪律落地）

每天 20-30 分钟，固定动作：

1. **挑 3-5 条利基热帖**（Claude Code / AI agent / DSH 生态，发帖 1 小时内的高信誉账号）；
2. **写有信息量的回复**：带具体经验、具体数字、可操作的补充——标准是「这条回复单独
   截出来也有价值」，一句话灌水是负反馈候选；
3. **回应自己帖子的每一条回复**（前 72 小时互动率影响分发，发帖后 24 小时内回全部评论）；
4. **不批量关注**：看到好账号先记下，每天至多零星关注几个，保持关注比健康。

红线回顾：举报 -369 / 屏蔽 -74 的量级意味着一次招人厌的互动抵掉几百个赞——
养号动作全部指向「被觉得有用」，无一指向「被觉得烦」。

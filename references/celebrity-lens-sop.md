# 名人视角引流内容 SOP（Celebrity-lens content playbook）

> **来源**：基于 `nuwa-skill`（花叔 AlchainHust，MIT）的"思维蒸馏"方法论 + 团队产品定位讨论（2026-09-14）整理。
> **本文档怎么用**：本文档给 **Buzz（GrowthMarketerAgent）** 用——把"名人思维视角"作为**引流内容钩子**，而不是做成产品里的常驻 Agent。核心纪律：**名人只出现在引流内容里，不进 Agent Team Playbook 的职能团队内核**。产品卖的是"能接单的职能团队"，名人是获客素材、不是卖点。
>
> **重要边界**：名人视角内容不得声称"名人本人推荐/ endorse 本产品"，不得伪造名人语录。所有名人观点必须标注"视角演绎 / 非本人原话"，避免虚假背书与侵权风险。

---

## 一、为什么这么用（定位纪律）

- **卖点 vs 钩子分开**：Agent Team Playbook 的付费价值 = 20+ 拟人化**职能 agent**（Scout 选品 / Hopkins 投递 / Justin 法务 / Kit 助理…）能替用户把生意跑起来。名人（乔布斯 / 马斯克 / 芒格 / Naval / 张一鸣 / Karpathy）是**思维顾问型评论员**，不接活、不交付。把它塞进"团队"会稀释"能干活的团队"这个最硬卖点。
- **名人是 commodity，不是护城河**：`nuwa-skill` 已把主流名人蒸馏成 MIT 开源 skill，任何人 `npx skills add` 就能装。若当产品卖点，等于用别人的开源产物给付费产品背书——买家自己装一个即可，无付费理由。
- **因此**：名人的**思维框架**拆进职能 agent 当方法论养料（由对应 agent 的 CLAUDE.md 吸收，不显名）；名人的**视角演绎**只用于 Buzz 的引流内容当钩子。

---

## 二、名人 × 职能 agent 映射表（钩子选题库）

每个引流选题 = 一个名人视角 + 一个你们真实职能 agent 的痛点场景。这样既借认知权威，又回扣产品内核。

| 名人 | 适配职能 agent | 钩子角度（引流选题方向） | 示例标题骨架 |
|---|---|---|---|
| **乔布斯** | Scout（选品）/ Wright（产品） | 极简、聚焦、砍掉 90% 功能；"用户不知道自己要什么" | 「如果乔布斯来审你的选品报告，他会先砍掉哪 90%？」 |
| **马斯克** | Scout / Markowitz（量化） | 第一性原理、硬核工程化、可量化迭代 | 「马斯克的第一性原理，怎么用在选品决策上」 |
| **芒格** | Markowitz / Victor（交易） | 多元思维模型、逆向思考、能力圈 | 「芒格的 10 个心智模型，能救你的选品盲区」 |
| **Naval** | Hopkins（接单）/ Kit | 杠杆（代码/媒体/团队）、复利、特定知识 | 「Naval 的三种杠杆，个人接单者怎么用」 |
| **张一鸣** | Buzz（增长）/ Scout | 延迟满足、数据驱动、AB 实验文化 | 「张一鸣的延迟满足，为什么对引流内容成立」 |
| **Karpathy** | Atlas / Anvil（开发） | 软件工程品味、AI 原生开发、可复现 | 「Karpathy 式的 AI 原生开发，你的 agent 团队该怎么搭」 |
| **Paul Graham** | Hopkins / Kit | 创业常识、做用户真正想要的东西 | 「PG 看一眼你的接单标书，会说哪句」 |

> 视角来源建议用 `nuwa-skill` 蒸馏出的心智模型（开源、可引用框架），不要自己编语录。蒸馏框架只作内部参考，不随开源仓库发布（放本地 `references/` 即可，已被 `.gitignore` 的 `docs/` 等忽略逻辑覆盖思路——本文档本身在 `references/` 下，属可开源的 Playbook 素材，不含私人信息）。

## 三、内容生产流程（Buzz 执行 SOP）

### Step 1 · 选题（每周 1–2 条，不刷屏）
- 从上方映射表挑 1 个名人 × 1 个职能 agent 组合。
- 选题判据：该职能 agent 当前在推的成品/方法论是否和该名人视角强相关（强相关才写，避免硬凑）。
- 统一打 `campaign_id`：`cel-lens-<名人slug>-<序号>`（如 `cel-lens-jobs-01`），供 Echo 归因。

### Step 2 · 写"视角演绎"正文（核心资产）
结构（参考 nuwa 的心智模型骨架，但**只为引流内容服务**）：
1. **钩子**：一句话把名人视角抛到用户痛点（如"你选了 20 个品，乔布斯会问：哪个是你真要做的？"）。
2. **3 个可迁移的心智模型**（取自名人真实公开观点，标注"视角演绎"）：每条 = 一句话模型 + 对"你的职能 agent 场景"的应用 + 局限。
3. **回扣产品**：末尾一段——"这些判断，我们的 Scout / Markowitz 日常就在用；Agent Team Playbook 把这类职能角色变成可接单的团队。"**不提名人 endorse**。
4. **诚实边界**：文末小字"本文为名人思维视角的演绎解读，非本人观点，亦不构成投资建议/商业背书。"

### Step 3 · 多渠道路由（严守 available-channels.md）
按渠道调性改写同一核心，不复制粘贴：

| 渠道 | 形态 | 注意（来自 china-outreach.md 价值先行原则） |
|---|---|---|
| **X (Twitter)** | 名人体视角短帖 + 长帖串 | 英文向，名人原著名言可引（标出处）；末尾带 `campaign_id` 追踪链接 |
| **小红书** | 图文笔记（"如果 XX 来帮你选品"） | 国内可直接成交，文末自然带产品/店铺；不硬广 |
| **知乎** | 回答体（"如何用芒格模型做选品"） | 先答问题建可信度，文末"顺便提一下"产品 |
| **B 站 / 视频号** | 短视频脚本（名人口吻拆解一个 agent 场景） | 脚本给 Wright/Atlas 复用；口播标注"演绎" |
| **YouTube** | 长视频脚本 | 同 X 长帖，英文向 |
| **Instagram** | 金句卡图 + 短文 | 视觉优先，引原著名言标出处 |
| ❌ TikTok / Gumroad | 不可用 | 严守 available-channels.md，不碰 |

### Step 4 · 链接与归因
- 每条内容带 `channel` + `campaign_id` 追踪参数，导向 Vendy 成交页（Buzz 不成交，只引流）。
- 写进 `artifacts/`（产物契约），供 Echo 复盘哪条名人钩子带来转化。

### Step 5 · 发布节奏
- 名人内容占比 ≤ 总引流内容的 30%（避免账号变成"名人语录号"，稀释职能团队卖点）。
- 同一名人同一角度，跨渠道 7 天内不重复硬推；遵循各平台冷却期（见 china-outreach.md 第四节）。

---

## 四、合规与声誉红线（必守）

1. **不伪造语录**：只用名人真实公开言论，且标出处；演绎部分明确写"视角演绎 / 非本人原话"。
2. **不虚假背书**：绝不写"XX 推荐 / 用过我们的产品 /  endorse"。名人只在"思维角度"出现。
3. **不蹭敏感/争议**：避开名人私人争议、政治立场，只取其**可公开、可商用的认知框架**。
4. **透明披露**：文末诚实边界小字不可省（见 Step 2.4）。
5. **调性匹配**：被动收入数字产品定位（passive-income-only.md）——名人内容最终必须回扣"一次产出、反复销售"的 Playbook，不导流到课程/咨询/服务。

---

## 五、效果验证（交给 Echo）

- 用 `campaign_id = cel-lens-*` 跑 4–6 周，让 Echo 对比：名人视角内容的点击率/转化率 vs 非名人内容。
- 判定：若名人钩子 CTR 显著高但**成交转化不高于基线** → 它只是吸引眼球、不强化卖点，应降频（回到 ≤15%）；若成交转化也高 → 维持 30% 上限，并扩名人库。
- 不凭感觉加名人 Agent；数据说话。

---

## 六、边界总结（一句话）

**名人 = 引流内容里的思维钩子，不是产品里的常驻 Agent。** 框架拆进职能 agent 当养料，视角只用在 Buzz 的引流内容，且永不虚假背书。

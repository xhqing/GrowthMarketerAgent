# AI 视频术语速查表（内部参考）

> 用途：写提示词、审片、与客户沟通时的常用术语对照。
> 原则：每个术语 = 一句话解释 + 场景用途，不追求教科书式严谨，追求「看一遍就能用」。
> 建立：2026-09-30（用户需求：非摄影背景，需要看懂运镜 / 景别等术语）。

## 一、景别（镜头离主体多远）

| 术语 | 一句话解释 | 什么时候用 |
|---|---|---|
| **远景** | 拍环境全貌，主体很小 | 开场交代场景（如「城市天际线」） |
| **全景** | 主体全身 + 周围环境 | 展示主体与环境的整体关系 |
| **中景** | 主体大半身（产品 = 完整罐体） | 最常用的「介绍镜头」 |
| **近景** | 主体局部（如罐子上半部） | 突出主体细节 |
| **特写** | 只拍细节（如罐身上的水珠） | 展示质感、情绪 |
| **微距** | 极近距离（如水珠上的反光） | 广告里「秀质感」的杀手镜头 |

**记忆口诀**：远→全→中→近→特→微距，是从「拉远」到「贴近」的顺序。

## 二、运镜（摄影机怎么动）

| 术语 | 一句话解释 | 提示词里的说法 |
|---|---|---|
| **固定镜头** | 机位不动，只有画面内容在动 | 「镜头固定」「固定机位」 |
| **推** | 镜头向前逼近主体 | 「缓慢推进」「缓缓推近」 |
| **拉** | 镜头向后远离主体 | 「拉远」「镜头后拉」 |
| **摇** | 机位不动，镜头左右转 | 「横向摇镜」 |
| **移** | 机位平移（像坐轨道车） | 「横向移动」「平移跟拍」 |
| **跟** | 跟随移动的主体 | 「跟随拍摄」 |
| **升降** | 镜头上下移动 | 「镜头缓缓升起」 |
| **环绕** | 绕着主体转圈 | 「环绕推进」（产品广告最常用组合） |
| **手持** | 轻微晃动（真实感 / 纪录片感） | 「手持感」「轻微晃动」 |

**产品广告最常用**：环绕 + 推进 + 慢动作——我们的 FLOE 片子用的就是这个组合。

## 三、角度（从哪个方向拍）

| 术语 | 一句话解释 |
|---|---|
| **平视** | 与主体同高（客观、日常感） |
| **俯拍** | 从上往下拍（展示全貌 / 压迫感） |
| **仰拍** | 从下往上拍（显得高大、威严） |
| **鸟瞰** | 垂直向下（宏大、上帝视角） |

## 四、光线（广告质感的关键）

| 术语 | 一句话解释 | 效果 |
|---|---|---|
| **顶光** | 从正上方打光 | 均匀、干净（产品摄影棚常用） |
| **侧光** | 从侧面打光 | 立体感强、突出纹理 |
| **逆光** | 从主体背后打光 | 轮廓发光、氛围感 |
| **侧逆光** | 侧后方打光 | 质感 + 轮廓兼得（**产品广告黄金布光**） |
| **轮廓光** | 把主体边缘「勾」出来的光 | 主体从背景中分离出来 |
| **柔光** | 柔和的光（阴影边界模糊） | 高级、干净 |
| **硬光** | 锐利的光（阴影边界清晰） | 强烈、戏剧、粗犷 |
| **黄金时刻** | 日出后 / 日落前的暖金色光线 | 温暖、高级、氛围满分 |

## 五、构图与画面

| 术语 | 一句话解释 |
|---|---|
| **中心构图** | 主体放画面正中央（产品广告标配） |
| **三分法** | 主体放在画面 1/3 线交点上（自然好看） |
| **对称构图** | 左右对称（庄重、仪式感） |
| **留白** | 画面刻意留出空间（高级感、好加字幕） |
| **浅景深** | 只有主体清晰、背景虚化（突出主体） |
| **焦外** | 虚化的部分（「焦外光斑」= 背景里的圆形光点） |
| **景深** | 画面中清晰的范围（深 = 前后都清楚） |

## 六、动态与节奏

| 术语 | 一句话解释 |
|---|---|
| **慢镜头 / 升格** | 把动作放慢（细节展示、情绪放大） |
| **延时摄影** | 把长时间拍成短时间（云流动、日夜交替） |
| **快切** | 镜头快速切换（节奏感、冲击力） |
| **转场** | 两个镜头之间的衔接方式（淡入淡出、划像等） |
| **节拍 / 节奏** | 镜头切换配合音乐的鼓点（卡点） |

## 七、AI 视频专有词（我们工作流里常说）

| 术语 | 含义 |
|---|---|
| **提示词（Prompt）** | 给 AI 模型的文字指令（内部工艺，不交付客户） |
| **首帧 / 尾帧** | 图生视频的起始画面 / 结束画面（控制镜头起点终点） |
| **参考图** | 给 AI 的参考素材（保持产品外观一致） |
| **多模态参考** | 图片 + 视频 + 音频一起作为参考输入（Seedance 2.5 能力） |
| **抽卡** | 同一提示词多次生成、挑最好的（AI 视频的常态工序） |
| **一致性** | 同一主体在多个镜头里保持相同外观（产品广告的硬指标） |
| **样片（Draft）** | 低分辨率快速试拍（2.5 支持，用来看方向对不对） |

## 八、客户沟通话术对照（说人话版本）

跟客户沟通时，把这些术语翻译成「客户听得懂的描述」：

| 术语 | 对客户说 |
|---|---|
| 环绕推进 + 特写 | 「镜头绕着产品转一圈慢慢靠近，重点拍质感」 |
| 侧逆光 | 「打光偏高级，像广告片那种通透视感」 |
| 浅景深 | 「背景虚化，突出你们产品」 |
| 慢镜头 | 「放慢动作，看着更有质感」 |
| 三分法构图 | 「产品不居中，画面更有设计感」 |

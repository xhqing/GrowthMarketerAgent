# 聚焦被动收入

做数字产品选品与变现方案时，聚焦**被动收入**，排除主动服务型收入。

## 算被动收入（可做）

一次产出、反复销售的数字产品——prompt 包、模板（Notion / Figma / Excel）、电子书 / 指南 / Playbook、素材库 / 资源包、小型自服务工具。制作完成后，销售与交付无需持续投入时间。

## 不算被动收入（默认不提议）

需要持续投入时间的主动服务——课程 / 训练营、代运营、咨询、定制服务、1 对 1 指导、会员社群运营。即使客单价高，也不纳入方案。

## 为什么

用户要的是可规模化、脱手后仍能产生收入的被动收入；主动服务会把自己绑死在时间里，违背初衷。

## 怎么用

设计变现路径时，只选「一次产出、反复销售」的形态；看到高客单机会（课程 / 服务 / 代运营）时，默认不写进方案，除非用户明确要求。

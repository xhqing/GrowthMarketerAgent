# 可用销售与引流渠道

做数字产品的销售与引流方案时，必须遵守以下渠道约束（用户环境限制，已两次踩到）。

## 不可用（不要再推荐）

- ❌ **Gumroad**：无法上架 / 收款 / 提现 —— 不要再推荐作为上架渠道
- ❌ **TikTok**：无法访问 / 发内容 —— 不要再推荐作为引流渠道

## 已验证可用

- ✅ **上架 + 收款 + 提现（海外 / 全球）**：Payloadz + PayPal
- ✅ **引流**：X (Twitter) / Instagram / YouTube + 中文平台（小红书 / 知乎 / B 站 / 视频号等）
- ✅ **小红书自带销售功能**（小红书店铺 + 个人售卖，支付宝 / 微信收款）——既是引流渠道，也是国内直接销售渠道，国内变现路径最顺，无需跳转 Payloadz

## 未验证、默认不推荐

LemonSqueezy、Paddle、Payhip、Ko-fi、Sellfy、Etsy、Pinterest、Reddit、Product Hunt、Hacker News。不要把方案建立在它们之上。

## 为什么

这些是用户的客观环境约束，推荐不可用渠道会导致方案无法落地、反复返工（已发生两次）。

## 怎么用

选品 / 销售 / 引流方案里，上架默认写 Payloadz + PayPal，引流默认写 X / Instagram / YouTube / 中文平台；若某方案必须用未验证渠道才能成立，先询问用户能否使用，再写进方案。

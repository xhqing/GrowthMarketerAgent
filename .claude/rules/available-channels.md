# 可用渠道（渠道约束）

> 权威口径 ｜ 最近更新：2026-10-02（**TikTok 由「不可用」改为「电脑端可用」**）

## 可用

| 渠道 | 用途 | 备注 |
|---|---|---|
| X / Twitter | 国际向引流与发帖 | 查询走隔离环境（见全局 CLAUDE.md「X / Twitter 查询必须带账号隔离」） |
| Instagram | 欧美向视觉内容 | 与 Facebook 同属 Meta，Reels 可一键同步到 FB 页 |
| YouTube | 长视频 / Shorts | 搜索长尾最值钱 |
| TikTok | 短视频 | **电脑端（网页版）可用**——上传、数据、评论走 web；移动端不可用（2026-10-02 修订） |
| 小红书 | 国内引流 + 店铺销售一体 | 既是引流渠道也是国内销售渠道 |
| 知乎 / B 站 / 视频号 | 国内内容 | 视频号偏国内投放与作品展示 |

## 不可用

- **Gumroad**：无法上架收款提现——不要用于上架或引流落地。

## 使用注意

- 发布、评论、点赞、关注等**写操作由真人手动执行**，不做 AI 托管运营（平台规则）；
- 引流链接必须带 `campaign_id` / UTM 供归因（当前链接资产见 `artifacts/handoff.md`）；
- 敏感信息（账户号、收入、个人配置）不入任何内容。

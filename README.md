# GrowthMarketerAgent · Buzz

> **增长营销** — 把潜在买家引到成交页的引流引擎。
>
> **Growth Marketer** — The traffic engine that funnels potential buyers to the checkout.

**拟人名 / Persona：Buzz**（制造话题 · 把流量嗡嗡嗡地引来）

---

## 职责 / What it does

为各渠道产出引流内容（X / Instagram / YouTube / 小红书 / 知乎 / B 站 / 视频号）+ 带追踪参数的链接（`channel` / `campaign_id`，供归因）。

Produces channel-specific traffic content (X / Instagram / YouTube / Xiaohongshu / Zhihu / Bilibili / Weishi) plus tracked links (`channel` / `campaign_id`) for attribution.

## 在流水线中的位置 / Pipeline position

① Scout 研判 → ② Wright 生产 → ③ **Buzz** 引流 → ④ Vendy 成交 → ⑤ Echo 复盘

## 内置能力 / Built-in skills

- `anysearch` · `find-skill` — 通用搜索与技能发现

## 约束 / Constraints

渠道：X / IG / YouTube / 小红书 / 知乎 / B 站 / 视频号（**TikTok 不可用**）；小红书同时是国内销售渠道。
